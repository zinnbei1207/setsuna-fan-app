# setsuna-fan-app
永遠のセツナ ファン向けWebアプリ / PWA

## LIVE予定の更新ルール（重要）

ライブ情報の正本は `app.js` の `liveEvents`。
今後ライブ予定を追加・解禁するときは、必ず以下のルールで更新する。

### 1. 公式解禁済みライブ
- `status: 'published'` で1公演ずつ登録する。
- 日付、タイトル、会場、OPEN/START、出演・特典会時間、料金、チケットURLなどは、公式告知で確認できた情報だけを入れる。
- 推測で詳細を補わない。
- ホーム、LIVE一覧、アプリ内LIVE CALENDARの表示元は `liveEvents` に一本化する。

### 2. 未解禁ライブ
- 予定を把握している場合は、1公演につき1件を `status: 'unreleased'` で登録する。
- 未解禁のイベント名・会場・時間などの内部情報は画面に表示しない。
- ただし、日付とその日の未解禁公演数はファン向けアプリに表示する。
- 表示文言は基本的に以下で統一する。

```
09.17 THU
LIVE
ライブ予定 1本あり
詳細発表をお待ちください
```

- 同じ日に未解禁が複数ある場合、本数は `liveEvents` 内の `unreleased` 件数から自動集計する。手入力で「2本」などを管理しない。
- 例：9/19に `unreleased` が2件なら「ライブ予定 2本あり」と自動表示する。

### 3. 同じ日に一部だけ公式解禁された場合
- 解禁された公演だけ、その既存データを `unreleased` → `published` に変更し、公式詳細を追記する。
- 同日に未解禁公演が残っていれば、公開済み公演は通常カード、残りは「ライブ予定 ○本あり / 詳細発表をお待ちください」として表示する。
- 未解禁本数は残っている `unreleased` だけを自動集計する。

### 4. ホームの NEXT LIVE
- `published` と `unreleased` の両方を日付順の候補として扱う。
- 直近2日分を表示する。
- `published` は通常のライブ詳細カード。
- `unreleased` は通常カードと同じレイアウト感で「ライブ予定 ○本あり / 詳細発表をお待ちください」と表示する。
- これにより、未解禁予定があるのに「次のライブが数週間後」に見える状態を防ぐ。

### 5. LIVE一覧 / LIVE CALENDAR
- LIVE一覧にも未解禁日を同じルールで表示する。
- LIVE CALENDARにも未解禁日をライブ予定日として表示する。
- カレンダーから未解禁カードへ移動する場合も、イベント名・会場などの未解禁詳細は出さない。

### 6. 終了判定
- `homeUntil` を過ぎた予定は今後のライブ表示から除外する。
- 未解禁予定は原則その日の `23:59:59+09:00` まで表示対象とする。
- Google Calendar等の履歴を削除するための処理とは分ける。

### 7. 更新時の安全手順
1. 必ず `zinnbei1207/setsuna-fan-app` の `main` 最新状態を取得する。
2. `README.md` のこのルールを確認する。
3. 最新の `app.js` と対象ファイルを取得してから編集する。
4. 既存ライブを推測で書き換えたり、別アプリのリポジトリと混同しない。
5. 公式解禁時は、既存の該当 `unreleased` レコードを更新することを優先し、同じ公演を重複登録しない。
6. 更新後、同日公演数・日付順・NEXT LIVE直近2日・LIVE一覧・カレンダー表示の整合性を確認する。

このルールは、2026-09-15時点のFan App仕様として固定する。
